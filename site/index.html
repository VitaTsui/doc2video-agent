把 PPT / PDF 变成讲解视频

解析幻灯片、分配时长、写稿、配音、设计镜头、渲染合成、质检——整条流水线是确定性的代码， 不是一次性的模型输出。改一页只重做一页。

MIT · GitHub · Python 3.11+ · macOS / Linux / Windows

产出的核心资产不是 MP4，而是可持续修改、可增量渲染的工程。 「第 7 页太长了，压到 20 秒」只会重写那一页的讲稿、重配那一段音、重渲那一个片段。

安装

一行试用 已验证

不装到系统里，直接跑一次。需要 uv。

uvx --from "doc2video-agent[bundled] @ git+https://github.com/VitaTsui/doc2video-agent" \
  doc2video run 你的文档.pptx "做一个 3 分钟的产品讲解视频"

[bundled] 会把 ffmpeg / ffprobe 一起装进环境，不用系统预装。 这条路走的是 ffmpeg 渲染器——能出片，但幻灯片是简版样式；要原样保真见下一条。

完整安装 已验证

源码安装，带上 Remotion 渲染器，幻灯片按原样渲染。

git clone https://github.com/VitaTsui/doc2video-agent
cd doc2video-agent

uv sync --all-extras          # Python 侧
cd renderer && pnpm install   # Remotion 渲染器（可选，但画质差别很大）

uv run doc2video doctor       # 看看少了什么

doctor 会逐项报告 ffmpeg、渲染器、语音、模型的可用性，以及缺了它会损失什么。

Docker 已验证命令

docker build -t doc2video .
docker run -p 8400:8400 \
  -e D2V_API_TOKEN="$(openssl rand -hex 32)" \
  -v "$PWD/storage:/app/storage" doc2video

令牌不能省：监听非回环地址却没有令牌时，服务会拒绝启动—— 容器里正是这种情况。

三种用法

给模型用（MCP）

这是它最初的形态：模型读完你的文档、按预算写好讲稿，剩下的交给它。

uv run doc2video serve      # 起服务，MCP 在 /mcp

claude mcp add --transport http doc2video http://127.0.0.1:8400/mcp \
  --header "Authorization: Bearer $D2V_API_TOKEN"
工具做什么
prepare_project解析文档，返回逐页内容和每页的时长/字数预算
render_video拿着你写的逐页讲稿，配音 → 镜头 → 渲染 → 质检
project_summary质量分与质检结果
revise_scenes只重做指定的几个场景

命令行

uv run doc2video run deck.pptx "做一个 5 分钟的讲解视频，面向工程师"
uv run doc2video show <project_id>    # 质量分、逐页讲稿、镜头
uv run doc2video metrics               # 跨运行的耗时与质量统计

HTTP

上传、解析、提交讲稿、订阅进度（SSE）、取成片，都是普通的 HTTP。

POST /uploads                          上传文档
POST /agent/prepare                    解析，返回逐页内容与预算
POST /projects/{id}/narrations         提交逐页讲稿，返回 job_id
GET  /jobs/{id}/events                 订阅进度（SSE）
GET  /projects/{id}/video              下载成片

讲稿从哪来

默认不持有模型、不需要任何 Key——讲稿由调用方（Claude、ChatGPT、你自己的 Agent）写好传进来。 如果调用方自己没有模型（比如桌面版），可以给它配一个：

方式说明
本机 CLI Agent 机器上装了 Claude Code 或 Codex 就能直接用，不要 API Key。经 agent-virtualization 接入，声明空动作集——要的是模型，不是让它在你机器上动手。
Anthropic / OpenAI / Gemini各自的官方接口
OpenAI 兼容通道DeepSeek、通义、月之暗面、自建网关，填 base_url 即可

任何一步拿不到模型答复——没配、调用失败、返回不合法——都会落到确定性的启发式规则上， 并在运行记录里留下降级原因。片子照出，只是那部分会平一些。
