# 渲染前的最后一遍：自己读

`check_script.py` 量得出的都量了——字数、超时、照读重合度、漏讲条目数、
字幕长度、格式脏东西。剩下这五类**只有读了才能发现**，而其中一类是真的讲错了。

这一遍在渲染之前做。之后再发现，就是重配音、重渲染。

## 怎么做这一遍

页数少（≤15）就自己读：把 `页面.md` 和 `讲稿/` 对着看一遍。
页数多，或者你已经写了很久、对稿子脸熟了，就**派一个执行员子智能体**去读，
给它这份文件、页面内容和讲稿，让它只回报问题清单。脸熟是真的会看不见问题的：
自己写的半句话，第二遍读还是会自动补全。

**不要打分，不要给总评，不要说哪里写得好。** 要的是「哪一页、哪一句、为什么不行」。

---

## 只找这五类

### 1. flat｜只是在读幻灯片

讲稿把页面上的短语连起来念了一遍，没有把它变成话。

> 页面：`企业定位 城市产业链智能创新生态运营商`
> 讲稿：「企业定位，城市产业链智能创新生态运营商。」
> —— 这是在读，不是在讲。

**但注意**：页面上本来就是完整口语的句子，照念是对的，不算这一类。

### 2. broken｜半句话

主语没了、中心词被删了、两件事用逗号硬接。

> 「简称 CCAI，是国家首批之一」——「之一」后面悬空，缺了中心词
> 「技术研发成果和数据资源的建设载体。」——这不是一句话，是个词组

### 3. drift｜事实漂移

讲稿说的和页面上写的不是一回事。最常见的三种：

- **归属**：别人的成果、已有的资产，被讲成「本项目做的」；
- **时态**：将要做的事被讲成已经做完；
- **数字和名称**：数字对不上，名字换了同义词、用了简称、削掉了「有限公司」这类后缀。

**这一类最重要。** 其余四类是不好听，这一类是讲错了——而它会被念出来，
配上正在屏幕上的原文。

### 4. jargon｜行话原样搬

页面上写着能看懂、念出来听不懂的词，直接搬进了讲稿。

> 「五方共建」——听的人不知道哪五方
> 「实体运营机构是……」——公文里的说法，不是说出来的话

### 5. seam｜页与页接不上

相邻两页之间有断裂：上一页留了个头没有收，或者这一页突然开始讲一件没交代的事。
也包括**开场雷同**：连着三页一个模子起头，听起来像模板。

---

## 判断的分寸

- **拿不准就不报。** 误报比漏报贵：每一条都要回去看一遍页面。
- **一页最多两条**，挑最要紧的。
- **报了就要能指出来**：引讲稿里出问题的那一句原文，不要转述。
- 封面、目录、章节页天然简短，不要按内容页的标准挑。

## 报回来的格式

一页一行就够，不用 JSON：

```
p05 drift  「本项目已完成大模型驱动的产业信息智能分析」
           页面写的是技术牵头方已有的成果「可被本项目借鉴」，讲稿说成了本项目做完的
p12 broken 「是国家首批之一。」——「之一」后面悬空
```

## 改完之后

改 `讲稿/pNN.md`，重跑 `check_script.py`（改一句可能把字数改超），然后：

```bash
python3 scripts/make_video.py --dir <工作目录> --pages 5,12
```

**已经渲染过的，改哪几页就只重做哪几页**，其余片段原样复用——实测一页
9 秒跑完，整片重做是 20 多秒起。还没渲染过就正常整片跑。
