# 沙箱里怎么跑，成片怎么交出去

## 工作目录：先验可写

唯一的硬条件是**写得进去**。开工第一句：

```bash
D=/workspace/讲解视频 && mkdir -p "$D" && test -w "$D" && echo "可写：$D"
```

⚠️ **`/workspace/myspace/` 未必可写。** 实测某平台上它是 root 属主，而 bash 以
ubuntu 运行，`mkdir` 直接 Permission denied。这件事上**不要耗时间**——sudo、
逐个目录探权限、找有没有用户专属子目录，都试过，都不解决。换 `/workspace/<名>`
就好，一句话的事。

**什么时候才必须用 `/workspace/myspace/`：要派子智能体的时候。** 那是主子之间
唯一共享的投影，你在 `/workspace/` 别处建的目录子智能体读不到。所以：

| 怎么跑 | 工作目录放哪 |
| --- | --- |
| 自己一个人跑完整条链路 | 任何可写目录，`/workspace/<名>/` 就行 |
| 要派子智能体（分片写讲稿、派人读稿） | **必须** `/workspace/myspace/<名>/`，且它得可写 |
| myspace 不可写，又想派活 | 派不了。要么自己写完，要么让平台方给可写目录 |

其余两条不变：

- **源文档读得到就行**，不必挪。在别处就 `stage_myspace_file` /
  `sandbox_put_artifact` 拉进来；
- 传给脚本的 `--out` / `--dir` 一律用**绝对路径**。子智能体的当前目录和你不一定
  相同，相对路径会落在别处；
- `/myspace/...`（不带 `/workspace` 前缀）在 bash 里 `find` 不到，那是网盘路径
  不是磁盘路径。

建议的布局：

```
/workspace/讲解视频/            ← 要派子智能体就换成 /workspace/myspace/讲解视频/
  <工作目录>/                   ← prepare.py --out 指到这里
    页面.md  预算.tsv  讲稿/  工程.json  状态.json  运行.log
    成片.mp4                    ← 交付的就是这一个
    工程库/                     ← 引擎的工程：页面图、每页配音、片段、成片
```

## 装依赖：一条命令串，不要拆两次

```bash
pip install /path/to/skill/vendor/doc2video_agent-*.whl --no-deps \
  && pip install -r /path/to/skill/requirements.txt \
  && python3 /path/to/skill/scripts/check_env.py
```

**派给子智能体的命令也要这样串成一条**，让它一次跑完：技能不随非执行员角色
继承，`pip install` 装的东西也不保证下一次调用还在。

⚠️ 派活只能派**执行员 worker**——探索员和审查员没有 Bash、没有文件写入，
脚本根本执行不了，而它报回来的会是「材料目录不存在」这类看着像材料问题的话。

## 外网：这条链路上唯一需要它的地方

播音腔在微软的服务器上（`speech.platform.bing.com`）。`check_env.py` 默认会真
合成一句话去试——装得上和连得通是两件事，而连不通的表现是**渲染跑到配音那一步
才失败**，那时候整份文档已经解析完了。

连不通没有本地替代（详见 [voice-and-timing.md](./voice-and-timing.md)）。
先解决网络，不要退而求其次。

## 优先要 PDF，不要 PPT

幻灯片渲染有三档，自动降级：

| 档位 | 依赖 | 保真度 | 沙箱里 |
| --- | --- | --- | --- |
| LibreOffice | 400MB+ 系统套件 | 最高（PowerPoint 自己的排版引擎） | 装不了 |
| Chromium | Remotion 装过的浏览器 | 高：主题色、字体、渐变、表格、图表 | 一般没有 |
| 内置栅格化器 | 无 | 低：只按 shape 几何画 | **PPT 落在这一档** |

**PDF 不走这三档**——PyMuPDF 自己渲染页面，和原稿一模一样，沙箱里也一样。

PDF 的另一半是文字层：没有的话（扫描件、导成图再拼的）先跑 `ocr_pdf.py` 补一层，
见 SKILL.md「开工前 · 3」。OCR 引擎的模型随 wheel 打包，**识别时不联网**——
这条链路上唯一要外网的还是只有配音。

所以拿到 `.pptx` 时，先问用户能不能给一份导出的 PDF。这比在沙箱里补渲染依赖
省事得多，效果还更好。（`.ppt` 旧版二进制格式**必须**先转 `.pptx` 或 PDF，
python-pptx 读不了它。）

## 字幕：沙箱里多半没有中文字体

字幕烧进画面靠 ffmpeg 的 drawtext，它要一个**有中文字形**的字体文件。精简镜像
通常只有 DejaVu，而 DejaVu 没有中文——FreeType 于是用「缺字符」的方框回答每一个
汉字，字幕就成了一片方块。引擎 0.10.31 起改成宁可不烧：找不到能画汉字的字体
就跳过字幕，并在 `summary.py` 的降级栏里说出来。

```bash
python3 scripts/check_env.py        # 「字幕字体」那一节报的就是这件事
```

**包里已经带了一份**：`vendor/fonts/NotoSansSC-Regular.otf`（8.3MB，SIL OFL 1.1，
许可证同目录）。整个技能包拷进沙箱就带着它，`lib/workspace.py` 自动把
`D2V_FONT_PATH` 指过去——沙箱里不用 root、不用联网、不用配。

要换别的：把 `.otf`/`.ttf` 丢进 `vendor/fonts/`，或者 `export D2V_FONT_PATH=<绝对路径>`
（显式的优先）。机器上本来就装了 `fonts-noto-cjk` 也行，引擎会找到。

真的一个能画汉字的字体都没有时，出片照常，只是没有字幕。**别把它当成没事**：
配音在讲，画面上没有字。

## 耗时与 120 秒的工具预算

| 步骤 | 量级 |
| --- | --- |
| `ocr_pdf.py`（只有图片 PDF 要跑） | 一页约 1 秒（200 dpi，实测 3 页 3.3 秒），30 页按半分钟估 |
| `prepare.py` | 秒级（9 页 pptx 实测 1.8 秒） |
| 写讲稿 | 看你，是这条链路上最花时间的一步 |
| `check_script.py` | 秒级 |
| `make_video.py` | **分钟级**：9 页 / 117 秒成片实测 19 秒（纯 ffmpeg 渲染器），30 页的片子按几分钟估 |
| `--pages N` 改一页 | 实测 9 秒——只重配那一页、重渲那一段 |

所以 `make_video.py` **默认后台跑**，立刻返回。轮询用 `job_status.py`，
它的 `--wait` 别超过工具预算——超时被打断的是轮询，渲染在自己的进程组里
继续跑，再调一次就好。

## 页数多的时候，派子智能体写讲稿

页数少就自己写：你手里有整份 `页面.md`，通读之后逐页写，是质量最好的做法。

页数多（20+）到一次写不完，再切片派活，**按章节切、不要按页数硬切**：

- 一片一个子智能体（**执行员 worker**），同时最多 3 个，回来一个补一个；
- 任务书里要带上：**整份文档的通读结论**（这份材料在讲什么、分几块、术语的准确
  写法）、这一片的页面内容、这一片每页的字数上限、
  [narration-writing.md](./narration-writing.md) 的正文；
- 让它把讲稿**直接写进 `讲稿/pNN.md`**，不要回报正文——回报正文等于把整份稿子
  再过一遍上下文；
- 切片的边界要落在章节之间。同一章跨两个子智能体，那两页之间接不上，
  而「接得上」正是这一步最难保证的东西。

全部回来之后由你自己跑 `check_script.py`，它是全局的：跨页开场雷同、
合计时长超标，只有合起来才看得见。

## 交付

沙箱里生成的文件只停在磁盘上，对用户是不可见的。**成片一定要走交付链路**：

```
sandbox_get_artifact 登记 → pin_to_workspace 交付
```

交付 `<工作目录>/成片.mp4` 这一个文件。中间产物留在工作目录里就行，同一会话内
够用；沙箱只在会话内持久，跨会话或环境重置后可能就不在了。

## 体积

9 页 / 117 秒的片子，实测：

| 东西 | 大小 |
| --- | --- |
| 成片 mp4 | 2.1 MB |
| 每页配音 wav | 4.9 MB |
| 场景片段 | 1.4 MB |
| 合成中间产物（out/） | 5.9 MB |
| 页面渲染图 | 0.5 MB |
| **工作目录合计** | **15 MB** |

按页数线性涨。工程库不是临时文件——留着它，下次改一页才只重做一页；
真要清理，删 `工程库/` 之前先把 `成片.mp4` 交付出去。
