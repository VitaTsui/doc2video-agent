# 分镜：把一份材料重新讲一遍

这一步决定整支片子。它不是把文档切成片段，是**重新组织**——你读完整份材料，
弄明白它在说什么，然后按「讲给人听」的顺序讲一遍。

## 一条铁律

**画面里不出现文档原文，也不出现文档的排版。**

上一版的技能包是对着页面讲解：画面就是那一页，镜头框住正在讲的那一块。这一版
不是。观众看到的是为这句话专门做的画面——一张图、一组数、一条流程——文档只是
你知道这件事的来源。

所以下面这些都是错的：

- 把一页的正文原样搬进 `narration`
- 让某一场的画面「像第 7 页那样排」
- 一页一场，按页码顺序走完
- 把页面标题当场景标题

一页有三件事就拆三场，三页讲一件事就并一场。**页码不参与分镜，只参与追溯。**

## 契约

写进工作目录的 `分镜.json`：

```json
{
  "title": "大企业培育数智化情报支撑方案",
  "scenes": [
    {
      "id": "scene-001",
      "rollType": "a-roll",
      "beat": "开场：这份方案要解决什么",
      "narration": "大企业培育缺的从来不是数据，是把数据变成判断的那一步。",
      "visual": "一句话标题落到纸面上，下方三个灰色问号淡入",
      "keyPoints": ["痛点是判断，不是数据量"],
      "sourcePages": [1, 3]
    }
  ]
}
```

| 字段 | 是什么 | 要求 |
| --- | --- | --- |
| `id` | `scene-001` 起，按顺序，不跳号 | 组件名和音频名都从它来 |
| `rollType` | `a-roll` 或 `b-roll` | 见下面「A 还是 B」 |
| `beat` | 这一场在整片里干什么 | 给人看的，不进画面 |
| `narration` | 这一场要念的话 | **成片里唯一被念出来的东西** |
| `visual` | 画面要做成什么样 | 写给场景开发的一句话意图 |
| `keyPoints` | 这一场要让人记住的 | 1–2 条，多了说明该拆 |
| `sourcePages` | 依据来自原文哪几页 | 只为追溯，可以为空 |

`id` 必须连号，因为时间轴、音频文件、组件文件三者靠它对齐。

## 分多少场

`prepare.py` 会按目标时长报一个区间，那是护栏不是指标。真正的判据只有一条：
**一场讲一个意思**。

- 一场 8–25 秒。短于 8 秒观众刚看懂画面就切走了；长于 25 秒的一场里必然不止
  一件事。
- 讲稿写多长都行，**不用卡字数**——时间轴是配完音量出来的，画面会跟上。这是
  这一版和上一版最大的不同，上一版超预算就得整份重写。
- 但别把「不限字数」当成可以啰嗦。一场超过 25 秒就是该拆的信号。

## 顺序

按讲给人听的顺序，不是按文档的顺序。常见的一种：

```
是什么问题 → 为什么难 → 怎么做 → 做成什么样 → 谁来做 / 什么时候
```

材料自己的章节顺序常常是「组织架构 → 技术方案 → 预期效果」，那是写给评审看的
顺序，念出来没人听得下去。

## A 还是 B

- **A-roll**：默认。信息本身就是内容——数据、结构、流程、对比、清单。画面是
  为这句话生成的动画。
- **B-roll**：气口和转场。一段没有具体信息、起承接或情绪作用的话，配一段纸艺
  质感的画面。**B-roll 全片不超过 15%，单场 4–8 秒。**

判断很简单：**这句话里有没有必须让人看见的具体东西？** 有就是 A-roll。
「我们来看第二部分」没有，是 B-roll 的料。

B-roll 需要环境里有生图和生视频能力。没有的话，`broll-director.md` 说了怎么办
——简单说是全部退回 A-roll，而不是留一段黑画面。

## 讲稿

讲稿写在这里，和分镜一起定，因为一场讲什么和这场画什么是同一个决定。

三条准则，冲突时按这个顺序：**讲全** > **有出处** > **能念**。

- **讲全**：这一场答应过要讲的东西，讲完。`keyPoints` 里写了两条就讲两条。
- **有出处**：每句话都能在素材里找到依据。原因、影响、预测，材料没写就不要讲
  ——它会配着一个煞有介事的画面播出去。
- **能念**：写的是要念出来的话，不是要读的字。长句拆开，书面语换成口语，
  括号里的补充要么删掉要么变成一句话。

数字念得出来才写：「同比增长 23.5%」可以，「23.5%↑」不行。

## 自查

写完跑一次：

```bash
python3 scripts/validate_storyboard.py --out <工作目录>
```

它查得出 id 不连号、缺讲稿、B-roll 超标、单场过长这类结构问题。查不出的只有
一件事，得你自己看：**这支片子讲下来，是不是一个人在把一件事讲清楚。**
