# B-roll：纸艺质感的气口

B-roll 是**气口**，不是内容。它接在两段信息之间，让片子有呼吸；它不承担任何
必须被看见的具体东西——那些都是 A-roll 的活。

所以只有两种话配 B-roll：转场（「说完能力，再看落地」）和情绪（「这件事没有
捷径」）。带数字、带清单、带结构的话一律 A-roll。

全片 B-roll 不超过 15%，单场 4–8 秒。`validate_storyboard.py` 会拦。

## 能力探测：先看有没有，再决定做不做

这条链路**不停下来问人**。开工前探一次环境：

- 有生图也有生视频 → 按下面做。
- 缺任何一个 → **把所有 B-roll 场次改成 `a-roll`**，在分镜里留一行说明，
  照常往下走。

改回 A-roll 不是降级成黑屏，是这一场改由动画来画。转场话配一个简单的画面
（一句话推入、一条分隔线扫过）完全成立——比空着强得多，也比停在那里等人强。

改完记得重跑 `validate_storyboard.py`，B-roll 占比那一条会跟着变。

## 风格

统一的一句话，每张图都带上，不要一场一个风格：

> 纸艺定格动画风格，手工剪纸与折纸的层叠质感，米白纸面，柔和的纸张纹理与
> 边缘毛边，侧光投下浅浅的纸影，低饱和的暖色调，无文字。

三个必须：

- **无文字。** 生成模型写不对中文，写出来的是似字非字的花纹，而画面上一有字
  观众就会去读。
- **不要人脸。** 生成的脸在定格质感里尤其恐怖，而且会抢走注意力。
- **构图留中间。** 字幕在下三分之一，主体压在正中偏上。

## 做

一场一张图，一张图一段视频，落进 `<工作目录>/项目/public/broll/`：

```
项目/public/broll/scene-004.png     图（中间产物，留着便于重做）
项目/public/broll/scene-004.mp4     视频，注册表认这个
```

文件名就是场景 id。`register_scenes.py` 按 `broll/<id>.mp4` 找，找不到就报
是哪一场缺素材，不会静默跳过。

视频提示词只描述**很小的动作**：纸片轻微浮动、光缓慢扫过、一层纸缓缓落下。
定格动画的味道来自克制的运动，镜头推拉和大幅位移会立刻穿帮。

**不要在提示词里要音效或配乐。** 成片的声音只有旁白，宿主会把素材静音——一段
自带音轨的素材不会毁掉片子，但会浪费一次生成。

## 长度对不上怎么办

素材通常 4–6 秒，槽位是配音量出来的，两者很难正好相等。宿主已经处理了：
短了放慢（不低于 0.5 倍速），长了裁掉，**槽位长度永远不变**。

所以不用为了对齐去重新生成素材。真正要避免的是差太多——一段 3 秒素材配 8 秒
槽位会明显发慢，那种情况把这一场的讲稿改短，或者干脆改回 A-roll。

## 自己验收

没有人工 Gate，所以生成完自己看一遍，至少确认三件事：

1. 画面里没有文字（尤其没有假汉字）
2. 没有人脸
3. 主体在中间偏上，下三分之一是空的

不合格就重生成。**不要把不合格的素材放进去等人发现**——这条链路上没有那个人。
