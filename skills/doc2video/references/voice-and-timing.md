# 播音腔，以及时长为什么改不动

## 音色是定的：`zh-CN-YunyangNeural`

这个技能包只用这一个声音，脚本里写死，环境变量也由 `lib/workspace.py` 覆盖。

微软给这一组中文音色打的性格标签是 Professional / Reliable / Warm / Lively /
Cute / Passion——**Yunyang 是唯一 Professional 的那一个**，其余是暖的、活泼的、
甜的。讲一份材料，这个差别就是全部。

语速是它自己的 **0.86 倍**（-14%）。测过四档，同一段真实讲稿：

| 语速 | 时长 | 字/秒 |
| --- | --- | --- |
| -8% | 14.28s | 4.48 |
| -11% | 14.76s | 4.34 |
| **-14%** | **15.29s** | **4.19** |
| -17% | 15.84s | 4.04 |

-8% 听着仍然「有点快」。播音腔读一份材料不是整点新闻，四个字上下一秒，
是一个人讲清楚一件事的速度。

> Azure 文档说这个音色支持 `newscast`、`narration-professional` 这些风格标签，
> 但**免费的 read-aloud 接口不认**：它会把标签当正文念出来，11.3 秒的片子变成
> 17.3 秒，开头是「mstts express as style newscast」。所以性格来自语速，不是风格。

## 字数预算是从音色来的

`预算.tsv` 的 `目标字数` = `口播秒数 × 4.45`。

4.45 是**整片口径**：一份 30 页的真片子测下来，说话本身 5.15 字/秒，页内停顿
占掉约 14%，合起来 4.45。所以这个数已经把逗号句号的气口算进去了，
不要再自己留余量。

**换音色就要重算预算。** 这也是脚本不给换音色开口子的原因：讲稿是按 4.45 写的，
换成 `say`（4.50）或 Kokoro，预算就不作数了——而成片听起来「还行」，
没人会回头查它为什么变了。`make_video.py` 在播音腔不可用时**直接拒绝开工**，
要用别的声音得显式加 `--allow-fallback-voice`。

## 停顿由标点决定，不由你写

引擎按标点把一页切成若干「语音单元」，单元之间的气口是它挑的，不是合成器的
标点表给的：

| 标点 | 它是什么 |
| --- | --- |
| `。` | 一个想法说完了，最长的那个气口 |
| `；` | 两件并列的事之间 |
| `：` | 往后倾，引出下面的内容 |
| `，` | 单元内部的小停顿，由合成器自己带 |

**所以：想让它在哪儿停，就在哪儿点标点。** 不要写 `[停顿]`、`……`、空行或者
多余的空格来「控制节奏」——前两个会被念出来，后两个什么也不会发生。

## 成片比口播长，长在页面首尾

每一页的画面前后各留一段静音：**开头 1.1 秒，结尾 1.0 秒**。翻页要给观众一点
时间看清新页面，也不能让上一页的话压到下一页的画面上。

所以：`预算.tsv` 里 `口播秒数 + 2.1 ≈ 页面在屏秒数`，而 `check_script.py`
报的「合计口播」也小于成片时长。对目标时长时看的是成片，不是口播。

## 估算和实际有偏差，以 `summary.py` 为准

`check_script.py` 的秒数是**按字数估的**，实际是**合成完量出来的**。
两者差一成上下很正常，英文多的页面差得更多（英文按词计时，一个 `Doc2Video Agent`
比四个汉字慢）。

实测：一页估 6.5 秒，成片里那个场景 10.3 秒——其中 2.1 秒是首尾留白，
其余是英文。**要确认真实时长，跑完 `summary.py` 看逐场景秒数。**

## 多音字和英文缩写：交给它，不要管

引擎里有一套读音修正（多音字词典、把 `RAG` 拆成 `R A G`），**但对播音腔不生效**，
是有意的：这个引擎自己读多音字读得对，缩写也念得对，代码里标着
`reads_polyphones = True`、`spells_initialisms = True`，于是那一层直接跳过——
「它需要什么帮助都不需要，那就一点都别给」。

所以：

- 数字、缩写、专有名词**照页面原样写**，`12000`、`78%`、`PPTX` 都是对的；
- 万一某个词它念错了，**改讲稿的写法**（换个说法、加个词让上下文明确），
  没有词典可配——配了也不会被用上；
- 需要断句准确的长专名（「国家人工智能应用中试基地」），靠标点断开，
  不要靠空格。

## 网络断了会怎样

播音腔在微软的服务器上。开工前 `check_env.py` 会真合成一句话试，
`make_video.py` 也会在启动前拦一道。

真在半路断了（第 9 页断网）：引擎**重试一次**，还不行就换成这台机器上最好的
本地声音把剩下的页念完，并记一条降级——**运行不会失败**。这时候成片是半段
一个声音、半段另一个声音，`summary.py` 的「降级」一栏会写出来。
看到这一条就把网络恢复，然后：

```bash
python3 scripts/make_video.py --dir <工作目录> --pages <换了声音的那几页>
```

沙箱里没有 macOS 的 `say`，本地兜底多半是 Piper（要另下 61MB 模型）或者
**静音**。静音成片是废品：时间轴、字幕、镜头全对，就是没有声音——而且
它长得跟正常成片一模一样，不看降级记录看不出来。
